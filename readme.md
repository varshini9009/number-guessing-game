# Number Guessing Game

## Description
A simple, interactive Number Guessing Game developed using Python. The program generates a random number between 1 and 100, and the player has to guess the correct number. It provides hints and feedback to help the player find the number.

## Features
- Generates a random number between 1 and 100.
- Allows players to enter guesses until they find the correct number.
- Displays "Too high" or "Too low" based on the guess.
- Provides an even or odd number hint after 5 valid attempts.
- Tracks and displays the number of attempts.
- Handles invalid inputs using exception handling.
- Includes a play-again option.

## Technologies Used
- Python
- Random Module
- Functions
- While Loops
- Conditional Statements
- Exception Handling (`try-except`)

## How to Run
1. Make sure Python is installed on your system.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python main.py
```

## How to Play
1. Run the program.
2. Enter a number between 1 and 100.
3. Follow the "Too high" or "Too low" hints.
4. After 5 valid guesses, receive an even or odd hint.
5. Continue until you guess the correct number.
6. Choose whether to play again.

## Note
The game generates a new random number for each new round.
